## Web app

Run `cd web && npm ci && npm test && npm run build` for local validation, or `npm run dev` for development. Set Vercel's root directory to `web` and framework to Vite. Keep `main` as the production branch; feature branches generate review previews. The client queries Marquee tables directly with a publishable Supabase key and row-level security. Ingestion changes appear on reload without a Vercel redeploy. Vercel needs no service-role credentials. The preview uses the existing GameDeck owner's Supabase Auth identity; password sign-in works across origins. Email links require adding the preview URL to Supabase Auth's redirect allowlist.

The Library uses canonical episode completion coverage, counting each episode once with multiple source observations. Activity shows only Trakt and manual dated watches. Undated anime evidence is labeled separately on detail pages. One Piece and Fairy Tail are excluded from personal views. Manual check-ins write the current date; imported evidence is retained. Status, rating, and watchlist edits use `manual_locked`. The current catalog has no poster or streaming-provider fields, so title cards use typographic covers and provider availability is deferred until metadata exists.
